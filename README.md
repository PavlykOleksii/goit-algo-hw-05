# Порівняння алгоритмів пошуку підрядка

У роботі порівнювалися три алгоритми:

- Боєра-Мура;
- Кнута-Морріса-Пратта;
- Рабіна-Карпа.

Для кожної статті перевірявся пошук підрядка, який міститься в тексті, та підрядка, якого в тексті немає. Час виконання вимірювався за допомогою `timeit` для 100 запусків.

## Стаття 1

| Алгоритм             | Існуючий підрядок | Неіснуючий підрядок |
|----------------------|-------------------:|---------------------:|
| Боєра-Мура           | 0.000835 с         | 0.017044 с           |
| Кнута-Морріса-Пратта | 0.003705 с         | 0.130585 с           |
| Рабіна-Карпа         | 0.002823 с         | 0.134299 с           |

Для статті 1 найшвидшим був алгоритм Боєра-Мура.

## Стаття 2

## Висновок

У проведених тестах алгоритм Боєра-Мура показав найкращий результат для обох статей. Він був найшвидшим як для існуючих, так і для неіснуючих підрядків.

Алгоритми Кнута-Морріса-Пратта та Рабіна-Карпа також правильно виконали пошук, але витратили більше часу.

Результати можуть відрізнятися залежно від тексту, вибраного підрядка та комп’ютера, на якому запускається програма.
